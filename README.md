
# 🛒 বাজার দর | BazarDor

### বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর এক নজরে


##  Project Description

**বাজার দর (BazarDor)** is a responsive web application that helps users explore and compare the prices of essential products across different markets in Bangladesh. Users can view daily price changes, browse products by category, compare market-wise prices, and access detailed product information through a user-friendly interface. The application also provides secure authentication and user profile management.


## Technologies Used

- **Next.js** — React framework and application routing
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling
- **Better Auth** — Authentication and user management
- **Google OAuth & GitHub OAuth** — Social login
- **React Hot Toast** — Toast notifications
- **Lucide React** — Icons, if used
- **Git & GitHub** — Version control


## Key Features

- **Modern Homepage:** A clean homepage with a hero banner, price highlights, and product sections.
- **Daily Price Updates:** Displays products with increasing or decreasing prices and percentage changes.
- **Product Details:** Shows product descriptions, minimum price, maximum price, average price, and market-wise prices.
- **Category Browsing:** Browse products by category and sort them by price.
- **Secure Authentication:** Sign up and sign in using email/password, Google, or GitHub with Better Auth.
- **User Profile Management:** View profile information and update the user's name.
- **Responsive Design:** Works across mobile, tablet, and desktop screen sizes.
- **Toast Notifications:** Displays success and error messages for authentication and user actions.
- **Loading Skeletons:** Shows loading states while product data is being fetched.
- **Custom 404 Pages:** Provides friendly error pages for invalid routes and unavailable products.
